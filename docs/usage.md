# 使用文档

## 登录

安装脚本会初始化一个独立的面板密码。打开页面后，先输入这个密码完成登录。

登录成功后，面板会在当前浏览器里保留默认 `30` 天的登录态；只要继续使用同一浏览器访问面板，这个窗口会自动续期。

如果需要重置密码：

```bash
rm -f /etc/ruijie-panel/auth.conf
```

然后重新运行安装脚本。

## 页面功能

顶部有四个标签页。

### 状态

- 首屏大字显示是否联网，下方是「守护进程 → 锐捷认证 → 互联网」连接链路，哪一段断了会变成红色或黄色虚线
- 重新认证、主动下线
- 守护进程：运行时长、PID、上次认证时间，启动 / 重启 / 停止
- 健康监听：开启 `1 天 / 3 天 / 7 天 / 永久`，或手动关闭
- 最近 6 条日志，右上角色条每格代表一条日志，按级别上色

守护状态与核心一致：`ONLINE` 在线、`CHECKING` 检测中、`RETRYING` 重试中、`WAIT_LONG` 等待重试。

### 账号

- 修改用户名、密码（密码留空表示不修改）
- 学生账号切换运营商（电信 / 联通）；教师账号的运营商由核心配置决定，面板只显示
- 配置 HTTP / HTTPS 代理

### 日志

- 在认证日志和健康日志之间切换
- 按级别过滤，健康日志还可以按类型过滤
- 选择最近 100 / 200 / 500 条，开关自动刷新

### 系统

- 运行环境：平台、内核、架构、依赖、主脚本版本
- 关键文件路径
- 切换浅色 / 深色主题，退出面板

## 健康监听联动

如果主仓库版本支持健康监听，面板会额外显示：

- 健康监听是否已开启
- 剩余窗口时长
- 采样是否活跃
- 健康日志
- 运行环境（平台、shell、路径等）

如果主脚本版本过旧，面板会提示升级，而不是假装这些数据存在。

## 主题

默认浅色，可在「系统」页切换深色。选择保存在当前浏览器。

## 常用运维命令

```bash
/etc/init.d/ruijie-panel start
/etc/init.d/ruijie-panel stop
/etc/init.d/ruijie-panel restart
/etc/init.d/ruijie-panel reload
/etc/init.d/ruijie-panel enable
/etc/init.d/ruijie-panel disable
```
